# Contributing

koala-bot is open source and contributions are welcome. This is early-stage; the
design is still converging (see [`docs/open-questions.md`](docs/open-questions.md)).

- **Read first:** [`AGENTS.md`](AGENTS.md) (how this repo is organised) and
  [`docs/concept.md`](docs/concept.md) (what we're building and why).
- **Every artefact meets the 4Cs** — Correct, Complete, Coherent, Concise (see `AGENTS.md`).
- **Record durable decisions** in [`docs/decisions.md`](docs/decisions.md); raise unresolved
  ones in [`docs/open-questions.md`](docs/open-questions.md). Never let a project fact live
  only in chat.
- **Licensing:** contributions are accepted under the repo's tri-licence
  ([`LICENSING.md`](LICENSING.md)). Add an `SPDX-License-Identifier` header to new source files.
