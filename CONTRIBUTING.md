# Contributing

koala-bot is open source and contributions are welcome. This is early-stage; the
design is still converging (see [*Koala Bot Open Questions*](memory://main/robotics/koala-bot/koala-bot-open-questions)).

- **Read first:** [`AGENTS.md`](AGENTS.md) (how this repo is organised) and
  [*Koala Bot Concept*](memory://main/robotics/koala-bot/koala-bot-concept) (what we're building and why).
- **Every artefact meets the 4Cs** — Correct, Complete, Coherent, Concise (see `AGENTS.md`).
- **Record durable decisions** in [*Koala Bot Decisions*](memory://main/robotics/koala-bot/koala-bot-decisions); raise unresolved
  ones in [*Koala Bot Open Questions*](memory://main/robotics/koala-bot/koala-bot-open-questions). Never let a project fact live
  only in chat.
- **Licensing:** contributions are accepted under the repo's tri-licence
  ([`LICENSING.md`](LICENSING.md)). Add an `SPDX-License-Identifier` header to new source files.
