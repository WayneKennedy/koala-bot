# FreeCAD migration evidence — 2026-09-29

Legacy Python baseline: Git `640674481ea299191077560e15505c0a88ac33be` (captured before modifying generators).
`legacy-solids.tar.gz` contains all 24 right-hand design BREPs and the capture's
`parts.json`. `legacy-part-versions.json` is the original ledger. These are frozen
historical evidence, not current geometry inputs.

`comparison.json` compares all 19 production/coupon designs and five versioned
study designs with native FreeCAD 1.1.3 / OCCT 7.8.1. The former environment used
build123d 0.11.1 / OCCT 7.9.3. All 24 native models are valid, with their original
solid counts and bounds within numerical precision. The 22 designs other than
the following have maximum sampled skin distances below 0.000001 mm.

| Design | Old → native version | Maximum sampled two-sided skin distance |
|---|---|---:|
| thigh | v3 → v4 | 0.054968 mm |
| shoulder carrier | v3 → v4 | 0.006366 mm |

These are local rounded-corner differences between kernels, not moved joint
interfaces. Both versions remain unknown/unprinted. An attempted fillet-order
change did not survive native document recompute and was discarded. Current
recipes retain the valid native result and increase the physical part versions.
Earlier slices do not validate those new versions.

The report includes raw boolean differences, volume integration, bounds and
surface sample counts/distances. In particular, upper-arm boolean subtraction
reports a large false difference at coincident curved faces despite its
near-identical two-sided skin samples and volume. A zero boolean difference is
also insufficient on its own: the shoulder's local blend changes are detected
by surface sampling. UV sampling uses a 3×3 interior grid plus vertices; dense
engraved coupons use one interior sample per face. Samples outside the trimmed
face are excluded. These are digital checks, not continuous surface-equivalence,
physical fit, strength or loaded-motion proofs.

`part-versions.json` now uses fingerprint schema 3, generated by FreeCAD. Each
entry records the original source revision, old ledger and this comparison.
Only the two explicit physical version bumps add new print-history entries;
unchanged parts retain their recorded versions and printability status. Future
geometry changes must still bump versions and pass the ledger regression tests.

Native release validation: all document objects and fully constrained sketches
must be valid; final solid count, volume and bounds must survive saving,
reopening and forced recomputation. The archive manifest records checksums of
every Python/FCStd pair and its frozen Python dependencies. Current engineering
and document tests: 75 pass; [`nominal-audit.json`](nominal-audit.json) records
the passing fallback audit for all three poses.
The scope is nominal assembly clearance, not a new continuous travel approval.

The generated walking document was opened in the installed FreeCAD GUI with
79 visible component/reference shapes; its saved camera and visibility restored
without manual correction. [FreeCAD viewport](walking-preview.png).
